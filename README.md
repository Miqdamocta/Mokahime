## 🛠️ Technical Setup

This project is a lightweight verification server built with **Python** and **Flask**.

### 🚀 Deployment
This project is designed to be deployed on **Render.com**. 

1. Connect your GitHub account to Render.
2. Select the `mokahime-verify` repository.
3. Deploy as a **Web Service**.

### ⚙️ Configuration
The following environment variables are used:
- `CLIENT_ID`: Your Discord Application Client ID.
- `CLIENT_SECRET`: Your Discord Application Client Secret.
- `REDIRECT_URI`: The URL Render provides for your service.
